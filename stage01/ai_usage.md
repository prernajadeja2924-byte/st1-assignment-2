# AI Usage Documentation

## AI Tool Used
Microsoft Copilot

## How AI Was Used
AI was used as a tutor to help me understand the SmartCare Python prototype. I asked AI to explain the appointment-booking code, identify limitations and suggest possible improvements.

AI was also used to generate an alternative beginner-friendly approach for storing the patient name, practitioner name and appointment time. The suggested solution did not use a database or graphical user interface.

## Verification
I did not assume that the AI-generated suggestions were correct. I ran and tested the Python code myself using normal and unusual inputs.

I tested:
- A normal appointment
- A blank patient name
- Two appointments with the same practitioner and time
- Unusual or empty input values

The testing showed that input validation could detect a blank patient name. It also showed that the prototype could still allow double-booking for the same practitioner and time.

## My Responsibility
I reviewed the AI suggestions, tested the code, checked the results and made sure I understood the code before using it.
