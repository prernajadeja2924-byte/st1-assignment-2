# Stage 1 Reflection

Before using AI, I created a simple SmartCare appointment booking prototype in Python. The program stored the patient name, practitioner name and appointment time. I then improved the program by using a list, dictionaries and functions to organise and display appointment information.

AI helped me understand how the program could be organised more clearly and helped identify limitations in the original version. It also suggested ways that input validation and error handling could be improved. However, the AI made some assumptions about how appointment data should be stored and how the booking system should behave.

I verified the AI suggestions by running the Python program myself and testing different inputs. I tested a normal appointment, a blank patient name, two appointments with the same practitioner and time, and unusual inputs. The blank patient test produced a ValueError as expected. Testing also showed that the program could still allow two patients to be booked with the same practitioner at the same time.

The engineering work still required me to understand the code, run it, identify errors, compare the approaches and decide whether the AI suggestions were appropriate. This showed me that AI can assist with programming, but I still need to understand and verify the code myself.
